# LLM as Text Classifier — Replication Package

Data and code for the paper: **"Does classifying the summary match classifying the full text? A replication with LLMs"** (MSc thesis, UFPE).

## Overview

This repository contains the complete replication package for a study that investigates whether LLM-based text classification on summaries yields comparable results to classification on full articles. Three LLMs (ChatGPT/GPT-4o-mini, DeepSeek V4 Flash, Gemini 3.5 Flash Lite) classify 3,000 CNN news articles using six input types:

| Input type | Description |
|---|---|
| `full_text` | Original article text |
| `extractive_summary` | Gold-standard extractive summary (from corpus) |
| `abstractive_summary` | Abstractive highlights (from corpus) |
| `summary_chatgpt` | Abstractive summary generated by ChatGPT |
| `summary_deepseek` | Abstractive summary generated by DeepSeek |
| `summary_gemini` | Abstractive summary generated by Gemini |

Two classification methods are used per input: **single-label** (pick one) and **percent-distribution** (distribute 100% across 18 categories).

## Corpus

The CNN-Corpus, which gathers the news articles, reference summaries, and topical annotations used to build the answer key, was described by Lins et al. [[1]](#references), [[2]](#references). The corpus is **not included** in this repository due to licensing — access must be requested from the authors of the corpus.

Once obtained, place the data in `data/db3/` and see `src/newsclf/corpus_loader.py` for the expected format.

## Repository structure

```
src/newsclf/          # Python package (config, prompts, LLM clients, metrics)
scripts/              # Runnable scripts (classification, evaluation, baselines)
notebooks/analysis.py # Analysis notebook (generates all tables and figures)
tests/                # Test suite
data/
  answer_key/         # Ground-truth labels (weighted human annotations)
  summaries_*.csv     # LLM-generated abstractive summaries
results/predictions/  # Classification results (all 6 CSVs)
figures/              # LaTeX tables (.tex) and PDF figures
```

## Installation

```bash
# Clone and install
git clone https://github.com/camyllalima/newsclf_masterproject.git
cd newsclf_masterproject
python -m venv .venv
source .venv/bin/activate   # or .venv\Scripts\activate on Windows
pip install -e ".[dev]"

# Set up API keys (only needed to re-run classification)
cp .env.example .env
# Edit .env with your API keys
```

## Usage

### Reproduce the analysis (no API keys needed)

```bash
# Run the analysis notebook to regenerate tables and figures
cd notebooks
python analysis.py
```

### Re-run classification (requires API keys)

```bash
# Classify all articles with all providers
python scripts/run_classification.py

# Evaluate accuracy against ground truth
python scripts/evaluate_accuracy.py
```

### Run tests

```bash
pytest
```

## Key files

| File | Description |
|---|---|
| `data/answer_key/answer_key.csv` | Weighted ground-truth from 3 human annotators |
| `results/predictions/*/results_single_*.csv` | Single-label predictions |
| `results/predictions/*/results_percent_*.csv` | Percent-distribution predictions |
| `notebooks/analysis.py` | Full analysis: metrics, McNemar tests, confusion matrices |
| `src/newsclf/config.py` | Model names, labels, paths |
| `src/newsclf/prompt.py` | Classification prompt templates |

## Metrics

- **Cohen's Kappa** and **F1-Macro** (primary)
- Accuracy (secondary)
- McNemar test with Bonferroni correction (pairwise significance)
- Inter-model agreement (Cohen's Kappa between LLMs)
- Near-miss analysis (errors within human annotation space)
